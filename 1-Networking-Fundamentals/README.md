# 1: Networking Fundamentals

## Overview

This module covers foundational networking concepts required for SOC analysis and network security monitoring.

## Topics Studied

1. OSI and TCP/IP models
2. IPv4 addressing and subnetting
3. TCP and UDP protocols
4. Common network ports
5. TCP flags: SYN, ACK, FIN and RST
6. TCP three-way handshake
7. DNS queries and responses
8. DNS tunnelling and possible data exfiltration

## Practical Work

* Analysed DNS traffic using Wireshark.
* Identified TCP handshake sequences.
* Practised Wireshark display filters.
* Investigated a simulated TCP SYN port scanning scenario.
* Prepared a basic SOC investigation report.

## Key Learning Outcome

Developed foundational knowledge of network communication and basic packet analysis, with an understanding of how suspicious network behaviour can be investigated.

## Tools Used

* Wireshark
* Kali Linux
